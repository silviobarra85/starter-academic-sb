# PLAYER_TABLES_MOBILE_V575

V575 sostituisce l'approccio solo-CSS V574 con classi runtime dedicate.

## Tabelle interessate
- Area Squadra / Dashboard Presidente
- Rose
- Listone

## Classi runtime
- `fanta-player-table-v575-teamarea`
- `fanta-player-table-v575-rose`
- `fanta-player-table-v575-listone`

## Comportamento mobile
- Colori per ruolo: P giallo, D verde, C blu, A rosso.
- Header sticky/opaco.
- Prima colonna sticky/opaca.
- Nomi giocatore non tagliati.
- Stili separati per poter cambiare una tabella senza toccare le altre.

- `static/fanta-engine/css/player-tables-mobile-v575.css`
- `static/fanta-engine/js/ui/player-tables-mobile-v575.js`
- `static/fanta-engine/tools/audit-player-tables-mobile-v575.mjs`
