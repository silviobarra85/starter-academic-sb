# AI Assistant Handoff V681

V681 è un overlay solo sito per rifinire le card mobile del Listone.

Punti chiave:
- Non toccare ioSudo.
- Non toccare i dati.
- Il Listone mobile deve restare fuori dalla table, secondo la logica V676.
- Il badge `Modifica` usa classi nuove `site-listone-change-corner-v681` e `site-listone-change-badge-v681` per non ereditare dimensioni legacy.
- Il badge modifica deve essere blu, leggibile e non ridotto a un pallino.
- Label del badge:
  - `INVARIATO` per righe non cambiate;
  - `NUOVO` per nuovi giocatori;
  - `USCITO` per eventuali righe storiche rimosse;
  - box cambiate separate da trattino per variazioni rilevate.
