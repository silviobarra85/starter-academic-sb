# ioSudo V616

ioSudo resta una PWA collegata agli stessi dati Sudatori.

## Aggiornamento
V616 aggiorna la cache/app shell a `iosudo-app-v616` e legge il manifest Sudatori V616.

Non serve reinstallare la PWA dopo il deploy: chiudere e riaprire l'app. In caso di cache vecchia, aprire da browser e fare refresh.
