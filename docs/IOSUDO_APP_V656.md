# ioSudo V656

Patch mirata per ripristinare **Rosa** dentro le schede squadra.

La lista globale **GIOCATORI** resta alleggerita come in V655: non include i giocatori presenti solo nei rumor.

La rosa squadra, invece, resta disponibile dentro ogni squadra e mostra i giocatori della squadra caricati dal dataset Sudatori/listone/rose gia consolidati nel modello dati.
