# League Template Engine V502 - FantaMantraManager

Questa lega non viene trasformata dal template: il template serve solo per future nuove leghe.

Per una nuova lega usare:

```bash
node static/fanta-engine/tools/create-league-v502.mjs fantanuovalega --name "Fanta Nuova Lega" --short "FNL" --season "2026-2027"
```

Prima della produzione servono configurazione manuale, dati, Firebase/EmailJS dedicati o disabilitati, Netlify e test.
