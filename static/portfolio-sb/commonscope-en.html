PYTHON · FASTAPI · TOOL ROUTING

CommonScope.

Different tools. A shared language.

A research and teaching ecosystem for describing, registering and selecting software tools by their capabilities. A shared codebase lets internship and thesis students develop interoperable modules.

Open repository ↗GitHub releases ↗

Early prototype · research and internship projects

01

ToolRecord and registry

A shared schema describes tool capabilities, inputs, outputs, endpoints and status. The initial registry uses three demonstration records held in memory.

02

Request routing

The initial router ranks tools using an explicit score based on tags, requested capabilities and domain.

03

API and interface

FastAPI backend, interactive API documentation and a minimal web frontend to explore the registry and try request matching.

04

Five development tracks

Registry, router, ontology builder, blackboard and workbench are the modular tracks described in the student guides.

ARCHITECTURE

Inside the project

Python and FastAPI APIs; shared ToolRecord and ScopeRequest models; HTML/JavaScript frontend. Work focuses on capability representation, tool selection and incremental module integration.

README ↗Student projects ↗ToolRecord schema ↗

STATUS AND USE

The supplied code is a starting point: tool endpoints are demonstrations. Matching returns a ranking and does not execute tools. Persistence, ontologies and blackboard coordination are development tracks, not completed features.
