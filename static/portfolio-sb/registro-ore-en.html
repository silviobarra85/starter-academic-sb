JAVA · SWING · SQLITE

RegistroOre.

Academic time, organised in one place.

A desktop application to record, plan and summarise teaching, research and institutional work. Data remains in a local SQLite database, with no application server.

Open repository ↗GitHub releases ↗

Desktop application · macOS, Windows and Linux Mint

01

Calendar and activities

Multi-year records, multiple activities on the same day and repeated entries across dates.

02

Projects and missions

Project profiles with funding, acronym, role, dates, collaborators and documents. Missions linked to entries without duplicating hours.

03

Summaries and exports

Monthly, annual and per-project summaries, with CSV and Excel exports for review and sharing.

04

Local data and backups

Local SQLite database, daily backups and restore tools. Public distributions start without personal records.

ARCHITECTURE

Inside the project

Java Swing interface, SQLite persistence and Maven build. The repository contains source code, manuals, tests and packages for supported systems. Original code is MIT-licensed; AI-assisted development is disclosed in the README.
