CommonScope.

Strumenti diversi. Un linguaggio comune.

Un ecosistema di ricerca e formazione per descrivere, registrare e selezionare strumenti software in base alle loro capacità. La base condivisa consente a studenti di tirocinio e tesi di sviluppare moduli interoperabili.

Apri il repository ↗Versioni su GitHub ↗

Prototipo iniziale · ricerca e progetti di tirocinio

01

ToolRecord e registry

Uno schema comune descrive capacità, input, output, endpoint e stato dei tool. Il registry iniziale usa tre record dimostrativi in memoria.

02

Routing delle richieste

Il router iniziale ordina i tool confrontando tag, capacità richieste e dominio mediante un punteggio esplicito.

03

API e interfaccia

Backend FastAPI, documentazione API interattiva e frontend web minimale per esplorare il registry e provare il matching.

04

Cinque percorsi di sviluppo

Registry, router, ontology builder, blackboard e workbench sono i percorsi modulari descritti nelle guide per gli studenti.

ARCHITETTURA

Dentro il progetto

Python e FastAPI per le API; modelli ToolRecord e ScopeRequest condivisi; frontend HTML/JavaScript. Il lavoro si concentra su rappresentazione delle capacità, selezione dei tool e integrazione progressiva dei moduli.

README ↗Progetti studenti ↗Modello ToolRecord ↗

STATO E UTILIZZO

Il codice allegato è una base di partenza: gli endpoint dei tool sono dimostrativi. Il matching restituisce una graduatoria e non esegue i tool. Persistenza, ontologie e coordinamento tramite blackboard appartengono ai percorsi di sviluppo, non a funzionalità complete già disponibili.
