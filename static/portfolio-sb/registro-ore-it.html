RegistroOre.

Il tempo accademico, in un unico registro.

Applicazione desktop per registrare, pianificare e riepilogare le ore di didattica, ricerca e attività istituzionali. I dati rimangono in un database SQLite locale, senza un server applicativo.

Apri il repository ↗Versioni su GitHub ↗

Applicazione desktop · macOS, Windows e Linux Mint

01

Calendario e attività

Registro multiannuale, più attività nella stessa giornata e inserimenti ripetuti su più giorni.

02

Progetti e missioni

Schede con finanziamento, acronimo, ruolo, periodo, collaboratori e documenti. Missioni collegate alle registrazioni senza duplicare le ore.

03

Riepiloghi ed esportazioni

Viste mensili, annuali e per progetto; esportazioni CSV ed Excel per controllare e condividere i riepiloghi.

04

Dati locali e backup

Database SQLite locale, backup giornalieri e funzioni di ripristino. I pacchetti pubblici partono senza registrazioni personali.

ARCHITETTURA

Dentro il progetto

Java Swing per l’interfaccia, SQLite per la persistenza e Maven per la compilazione. Il repository contiene sorgenti, manuali, test e pacchetti per i sistemi supportati. Codice originale distribuito con licenza MIT; sviluppo con supporto di strumenti AI dichiarato nel README.
